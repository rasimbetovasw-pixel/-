# Түсінікті математика

## Құрылғыдағы ИИ көмекшісі

Көмекші ашық **Qwen2.5-Math-1.5B** моделін браузерде жергілікті іске қосады. Ақылы API кілті керек емес, ал есептің мәтіні сыртқы ИИ серверіне жіберілмейді.

1. Сайтты HTTPS арқылы аш (GitHub Pages қолдануға болады) немесе әзірлеу кезінде `localhost`-та аш.
2. Chrome сияқты WebGPU қолдайтын соңғы браузерді пайдалан. Құрылғыда графикалық үдету қосулы болуы қажет.
3. «ИИ-ді қосу» батырмасын бас. Алғашқы жолы модель мен оның графикалық файлдары интернеттен жүктеледі; бұл біраз уақыт, интернет трафигі, сақтау орны және құрылғы жады қажет етуі мүмкін.
4. Жүктелгеннен кейін есеп жазып сұра. Модель осы браузерде жауап шығарады; браузер оны кэште сақтай алады.

Егер құрылғы WebGPU қолдамаса немесе жады жеткіліксіз болса, модель іске қосылмайды. Мұндайда графикалық үдетуді қосып, жаңарақ браузер/құрылғыдан қайталап көр.

## GitHub Pages

Репозиторийдің **Settings → Pages** бөлімінде `Build and deployment → Source: GitHub Actions` таңда. `main` тармағына өзгеріс түскен сайын workflow сайтты жариялайды. Сайт мекенжайы: `https://rasimbetovasw-pixel.github.io/-/`.

## Құрылымы

- `index.html`, `style.css`, `script.js` — сайт, интерактивті сабақ және чат.
- `webllm-worker.js` — модельдің ауыр есептеулерін бөлек жұмыс ағынында жүргізеді.
- `.github/workflows/pages.yml` — GitHub Pages жариялау әрекеті.

ИИ нұсқасына WebLLM кітапханасы (Apache-2.0) мен Qwen2.5-Math үлгісі қажет. Бірінші іске қосқанда олардың файлдары CDN және Hugging Face-тен жүктеледі; жүктеуден кейін чаттың өзі жергілікті браузерде жұмыс істейді.
