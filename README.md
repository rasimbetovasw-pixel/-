# Түсінікті математика

## ИИ көмекшіні іске қосу

Көмекші OpenAI Responses API-мен сервер жағынан сөйлеседі. API кілті браузерге берілмейді.

1. OpenAI API аккаунтынан API кілтін жаса.
2. Node.js орнатылған компьютерде Vercel CLI орнат: `npm install -g vercel`.
3. Жобаның осы бумасында `.env.local` файлын жаса да, ішіне мына жолды жаз: `OPENAI_API_KEY=осында_API_кілті`. Кілтті ешкімге жариялама және репозиторийге қоспа.
4. Терминалда осы `outputs` бумасына кіріп, `npm run dev` орында. Алғаш рет Vercel аккаунтына кіруді сұрауы мүмкін.
5. Терминал көрсеткен жергілікті URL-ді браузерде аш.
6. Интернетке жариялағанда осы буманы Vercel-ге жүктеп, **Project Settings → Environment Variables** жеріне `OPENAI_API_KEY` мәнін енгіз. Кейін қайта deploy жаса.

`OPENAI_MODEL` орнатпасаң, көмекші `gpt-4.1-mini` моделін қолданады. API қолданысы OpenAI аккаунтындағы қолданыстағы тарифке сай есептеледі. Сұрақтар жауап дайындау үшін OpenAI API-ге жіберіледі; оқушылардан аты-жөн, телефон не басқа жеке дерек сұралмайды.

## Құрылымы

- `index.html`, `style.css`, `script.js` — сайт пен интерактивті сабақ.
- `api/tutor.js` — ИИ көмекшіге арналған сервер endpoint.
- `.env.example` — орта айнымалысының үлгісі. Нақты кілтті тек `.env.local` ішінде не хостинг баптауында сақта.
